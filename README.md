# MRSURVIV0R'S VR HUB

**Version 0.9.95 · Early Access · 54 supported games**

A hub for installing and managing supported VR mods, with guided setup for PCVR and standalone Meta Quest. Spend less time sorting through installation steps and more time playing your favorite games in VR.

## Download

Open this repository's **Releases** section and download **MRSURVIV0RS-VR-HUB-0.9.95.zip** from **Assets**.

Choose the VR HUB ZIP, rather than GitHub's automatically generated **Source code** downloads.

You can also find downloads, setup guides, videos, and the full supported-game list on the [official website](https://mrsurvivor-installers.com/).

## Getting started

1. Download the VR HUB ZIP and extract it to a folder on your PC.
2. Open the VR HUB from the extracted folder.
3. Choose your game and follow its setup instructions.

Platform and storefront support vary by game. Some setups require you to select your own legally obtained game files. Check the supported-game list and the instructions for your chosen game before installing.

## What's new in 0.9.95

- **Black Mesa VR:** Added official GitHub release handling, Blue Shift support, and direct VR launching.
- **Perfect Dark VR:** Added support for both PCVR and standalone Meta Quest.
- **7 Days to Die VR:** Added automatic Steam detection and manual game-folder selection for other storefronts and custom installations.
- **Mario Kart Wii VR:** Added support through the official WiiCompiled workflow.
- **Resident Evil 7 Reloaded:** Restored support with the current installation and update workflow.
- **Resident Evil 4 Remake:** Updated for Talemann's RE4VR 2.1 release and official installer workflow.
- **Crysis VR:** Updated for the current mod package, with the patch for 64-bit memory crashes available under optional installs in the game area.
- **F.E.A.R. VR:** Expanded detection to include Steam alongside GOG and manual folders.
- **Update notifications:** Added passive notifications for several GitHub-backed mods, including Black Mesa VR, Perfect Dark VR, F.E.A.R. VR, DOOM (2016) VR, Halo MCC VR, and Mario Kart Wii VR.
- **Standalone Games Only filter:** Find standalone headset releases more easily.
- Additional installer, update tracking, Ready-state layout, and reliability improvements across supported games.

## Supported games

Version 0.9.95 supports 54 games across PCVR and standalone Meta Quest, including Resident Evil titles, Half-Life 2 Quest, Cyberpunk 2077, Portal 2, Ready or Not VRO, Black Mesa VR, Perfect Dark VR, and more.

Visit the [VR HUB Game List on the website](https://mrsurvivor-installers.com/) for the full game and platform breakdown. Support for a game does not mean every storefront or headset is supported.
